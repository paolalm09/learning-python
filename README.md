#Solar System Quiz
this is an 8-question quiz that determines whether the user can name each of the planets in order of how close they are to the sun.
How to run the game:
run the code directly inside the terminal or command prompt
Features of the game:
- It has a prompt for yes or no questions
- it uses .lower() so capitalization mistakes doesn't penalize players
- has an automatic score tracking and at the end of the game it tells you your final score
What I learned:
I learned how to manage variables to track cumulative scores, using .lower() so the user doesn't get marked wrong for their capitalization, and type casting integers into strings (str()) so it comes out looking clean in the terminal when the print statement gets outputted
Future Improvements:
- adding a play again loop so users don't have to restart the script manually
- I want to learn to randomize the question order
